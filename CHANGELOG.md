# Changelog

All notable changes to Game Tracker will be recorded here.

This project follows [Semantic Versioning](https://semver.org/):

- **Major** (`2.0.0`) for incompatible changes.
- **Minor** (`1.1.0`) for backward-compatible features.
- **Patch** (`1.0.1`) for backward-compatible fixes.

### Added

## Release process

When the unreleased work is ready:

1. Rename `Unreleased` to the release version and date.
2. Commit the changelog update to `main` through a pull request.
3. Create an annotated Git tag such as `v1.0.0` on that merge commit.
4. Push the tag and create a GitHub Release from it.
